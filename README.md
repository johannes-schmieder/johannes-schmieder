## fe-tools

Tools for estimation and variance decomposition in models with high-dimensional fixed effects.

| Repository | Purpose |
| --- | --- |
| [fevc](https://github.com/johannes-schmieder/fevc) | Bias-corrected variance components in worker–firm fixed-effects models, using the leave-out approach of Kline, Saggio, and Sølvsten. |

[Browse the fe-tools family](https://github.com/search?q=user%3Ajohannes-schmieder+topic%3Afe-tools&type=repositories)

## Numerical solvers

| Repository | Purpose |
| --- | --- |
| [CMG](https://github.com/johannes-schmieder/CMG) | Rust implementation of Combinatorial Multigrid for graph Laplacians and SDDM systems. |
| [MultiwayMG](https://github.com/johannes-schmieder/MultiwayMG) | Experimental Rust solver for problems with three or more high-dimensional categorical fixed effects. |
| [within](https://github.com/johannes-schmieder/within) | Fork of a solver library for projecting out high-dimensional fixed effects. |
